# Logos

Put the two logo files here, exactly as provided. Don't redraw them.

- `colorado-radon-program-logo.<ext>`: this is the image inside `Reference/colorado-radon-program-logo.png/`.
- `radonsketch-logo.<ext>`: this is the image inside `Reference/radonsketch-logo.png/`.

Then set `CONFIG.logos.program` and `CONFIG.logos.radonsketch` in `shared/data.js` to the file names.

Until you do this, both prototypes show a labelled placeholder box wherever a logo appears. The Reference folder wasn't available when the prototypes were built.
